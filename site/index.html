Unggah web

Pick a ZIP, choose a repo and branch, and see exactly what would change. Files in the ZIP are added or updated; nothing in the repo is removed unless you tick the removal box. This is the browser version of the Unggah Android app, which pushes a ZIP over SSH.

  1. ✓ Signed in
  2. Grant the Unggah app your repo on GitHub (choose Only select repositories; it asks for read & write code, nothing else). Skip if you already granted it.
  3. Pick a ZIP below, compare, commit.


    Your ZIP is read in this browser; when you commit, files go straight from this browser to api.github.com. The page never asks for a password or a token: sign-in happens on GitHub's own page, you choose which repos the Unggah app may access, and the sign-in lives only in this tab's memory (gone when you reload or it expires).
