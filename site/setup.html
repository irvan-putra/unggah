Unggah: one-time GitHub App setup

This creates the Unggah web GitHub App on your account with exactly these settings:

  • Permission: Contents: read & write (nothing else)
  • You pick which repos it can touch when you install it
  • Callback: this site's page; webhook: off; public app

    • The button opens GitHub's own page. You confirm the name there and click create.

App created. Two values come back:

1. Client ID (not secret; paste it in chat so the site config can be updated):



2. Client secret (SENSITIVE):




The client secret goes only into the NEO portal as the app's environment variable
UNGGAH_GITHUB_CLIENT_SECRET. Do not send it in chat, do not commit it, do not paste it anywhere else.
This page does not keep it: reload and it is gone.


The private key and webhook secret GitHub also generated are not shown and not needed; you can ignore them.
